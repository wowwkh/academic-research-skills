## Current package count

The retained main-text package contains **three tables and no final figure**. This is intentionally below the journal display limit while the conceptual model and any figure legend remain under review. No exploratory forest plot, historical PRISMA figure or legacy biomarker table is silently relabelled as supplementary information.

## Caption and labeling safeguards

- Table 1 states that derived values are not author-reported CIs and that it is not a primary pooled estimate.
- Table 2 states that article-level records are not independent cohorts or interchangeable biomarker studies.
- Table 3 states that it is a prospective design recommendation, not a current extraction table.
- Any future Figure 1 must label SLIM, mitochondrial dynamics, cGAS–STING and NLRP3 as proposed or transfer hypotheses unless a new SHSQ-25-defined human direct record closes the relevant evidence gate.
- Display numbering must remain stable when the final submission file is typeset; numeric reference order is audited separately in file 54.

## Submission decision

The three retained tables are eligible for a working submission package. The package is **not final** until the author-confirmed title page/declarations, figure decision, supplementary-information decision and final journal-format cleanup are completed. This display gate does not change the evidence hierarchy, the 19-anchor register or the primary pooled direct-cortisol decision.
