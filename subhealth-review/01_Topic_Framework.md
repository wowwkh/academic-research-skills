## 0 核心结论（先说）

**亚健康和你之前担心的 ASTI 一样，“宽”是陷阱。** 检索显示：

- “亚健康”泛综述已饱和：`J Ethnopharmacol` 2024 泛炎症综述、*Integrative Medicine Discovery* 2024 亚健康症状簇综述[1]、*Clinical Interventions in Aging* 2025 老年亚健康 TCM 管理模型[2]，都是“大而全”。
- 真正空白：**按症状簇收窄 + 单一生物学轴深挖 + 中医治未病理论钩子**。这正是范文①的公式。

**可直接复用的范文①公式：**

```
标题 = 基于[中医理论]探讨[细胞/分子单一轴]调控[窄疾病/窄状态]的机制及中医药干预策略
结构 = 中医理论内涵（纯中医，3节递进）→ 现代机制（纯现代，单轴）→ 二者对接章（生物学纽带，立论核心）→ 按治则分的干预策略 → 总结展望
图表 = 正文 1 图 + 0 表（汇总表进增强出版附加材料），若期刊不支持增强出版则正文只留 1 张时相/网络主图 + 1 张证据矩阵
写法 = 中药条目三段式：中医功效定位 → 现代药理机制 → 证据与出处
小标题 = 结论式，不是话题式
```

## 1 亚健康领域的竞品扫描（2024-2026）

| 赛道 | 代表文献 | 特点 | 你的胜算 |
|------|---------|------|---------|
| **泛亚健康（最宽）** | Integr Med Discov 2024: 亚健康症状簇的临床与基础研究进展（疲劳、心血管、感冒、胃肠）[1] | 5大症状域全覆盖，无机制轴 | 极低，已是教科书 |
| **老年亚健康** | Dove Press CIA 2025: 老年亚健康 TCM 管理模式回顾性队列 n=180[2] | 偏管理学/护理，无分子机制 | 低 |
| **疲劳性亚健康（最拥挤但最成熟）** | 国家十一五支撑计划系列：疲劳性亚健康量表、中医药干预评价、药膳干预 | 有量表 SHSQ-25，但机制多为泛泛“抗氧化/抗炎” | 中，需单轴突围 |
| **机制轴已占坑** | HPA轴-抑郁/失眠共病综述 2024-2025[3]；肠-脑轴调亚健康 2025 | HPA、炎症、线粒体各自有人做，但**未与治未病理论做生物学对接** | **中-高，空白在对接章** |

**关键情报：**
1. 疲劳性亚健康是亚健康中最接近“窄疾病”的亚型，有明确的诊断标准（SHSQ-25 ≥35分，18症状持续>3月，无器质性疾病）[2]
2. 中医“治未病”三层含义（未病先防、既病防变、瘥后防复）天然对应亚健康的“防-调-复”三阶段，但**尚无综述把它和单一分子轴做双向映射**——这是范文①第3章“生物学纽带”的机会
3. 你 ASTI 稿里最值钱的“证据分级 α/β/γ + 时窗矩阵”可直接迁移：亚健康研究同样存在“直接证据少、跨病种外推多”的问题

## 2 三个定稿选题（按辨识度排序）

### 方案 A（最推荐，完全同构范文①）

**题目：基于“脾虚生疲”理论探讨线粒体能量代谢重编程调控疲劳性亚健康的机制及中医药干预策略**

- **中医理论钩子：** 脾主运化，脾虚生疲（《脾胃论》“脾胃内伤，百病由生”；《黄帝内经》“脾气散精，上归于肺”）。这是范文①“脾不散精”的姊妹理论，期刊编辑一看就懂
- **窄状态：** 疲劳性亚健康（SHSQ-25 疲劳维度），而非泛亚健康
- **单一机制轴：** 线粒体能量代谢重编程（PGC-1α/TFAM/mtDNA复制、糖酵解/OXPHOS切换、过度自噬、ROS/MDA）。对应 ASTI 稿里的“代谢重编程”单轴
- **辨识度：** ★★★★★，因为“脾虚-线粒体”已有零散实验证据（黄芪多糖→PGC-1α↑[检索1]、生脉饮→抑制心肌线粒体过度自噬），但无人系统综述
- **落点：** 干预策略（有主张），不是研究进展（无主张）

**一句话卖点：** 现有亚健康综述都在说“抗疲劳”，本文说“**为何会疲**：脾虚导致线粒体能量工厂停摆，中药如何重启”。

### 方案 B（次推荐，HPA轴-炎症双轴，但包装成单轴）

**题目：基于“肝郁脾虚”理论探讨HPA轴-低度炎症网络调控心理性亚健康的机制及中医药干预时窗**

- **钩子：** 肝郁脾虚（情志-消化共病，正好对应亚健康的心理-躯体共病）
- **窄状态：** 心理性亚健康/压力性亚健康（焦虑、失眠、注意力不集中）
- **单一轴（包装）：** HPA轴失调→皮质醇昼夜节律紊乱→低度炎症（NF-κB↑、IL-6↑、TNF-α↑）→IDO-犬尿氨酸通路→5-HT↓。名义上是HPA轴，实质包含炎症，但对外宣称单轴
- **辨识度：** ★★★★，适合投《中国实验方剂学杂志》心理相关栏目
- **风险：** HPA轴综述已多，需靠“时窗”创新（何时用疏肝、何时用健脾）

### 方案 C（保守，纯治未病框架）

**题目：从“未病先防”到“既病防变”：慢性低度炎症视角下中医药早期干预亚健康状态的机制与策略**

- **钩子：** 治未病三阶段（经典，安全）
- **窄状态：** 亚健康向慢性病转化的临界态（仍偏宽）
- **单轴：** 慢性低度炎症（Inflammaging，CRP、IL-6轻度升高）
- **辨识度：** ★★★，适合《中草药》等宽口径期刊，但易被审为“泛综述”

> **决策建议：选 A。** 理由同你 ASTI 的决策：窄选题 + 理论钩子 = 高辨识度；宽选题 + 无钩子 = 看起来像没人要的边角料。

## 3 章节骨架（对齐范文①，5章结构）

```markdown
1  疲劳性亚健康“脾虚生疲”病机的理论内涵          ← 纯中医，3节递进（照抄范文①第1章）
   1.1 脾主运化是精微布散与能量生成的生理基础      （正常生理，引《内经》“脾气散精”原文）
   1.2 脾虚失运是气血生化不足与疲劳的核心病机      （病机起点）
   1.3 痰湿内蕴与清阳不升是疲劳迁延的病理枢纽      （病理结局，痰湿≈线粒体功能障碍的宏观表征）

2  线粒体能量代谢重编程驱动疲劳性亚健康的分子机制  ← 纯现代，单轴（压缩你原稿3.3为1章）
   2.1 线粒体作为细胞能量枢纽的生理功能
   2.2 疲劳状态下线粒体功能障碍的分子表征：OXPHOS↓、糖酵解代偿↑、ROS↑
   2.3 线粒体过度自噬与生物发生失衡：PGC-1α/TFAM轴抑制

3  线粒体功能障碍是连接“脾虚生疲”与疲劳表型的生物学纽带  ★立论核心，对应范文①第3章
   3.1 能量代谢重编程是脾虚失运的微观映射（脾虚≈ATP生成不足）
   3.2 线粒体ROS与炎症放大是痰湿内蕴的分子表征（含图1主图）
   3.3 生物钟-线粒体互作解释“晨轻暮重”的昼夜节律

4  基于“脾虚生疲”理论的中医药调控策略          ← 按治则分，不是按化学分类（关键！）
   4.1 健脾益气以培其本（治本）：黄芪、人参、党参、白术 → PGC-1α/TFAM
   4.2 化痰祛湿以治其标（治标）：陈皮、茯苓、薏苡仁 → ROS/MDA↓、SOD↑
   4.3 疏肝健脾以调其枢（调枢）：柴胡、白芍、香附 → HPA轴-CORT↓、NF-κB↓
   4.4 外治与综合干预：艾灸足三里、八段锦、药膳（对应“治未病”综合管理）

5  总结与展望（单章，占全文5-8%，3段式）
   5.1 机制链条总结：脾虚→线粒体功能障碍→疲劳（1段）
   5.2 已有方药与通路归纳（1段）
   5.3 不足+未来方向（1段，3条）：证据分级瓶颈/时序给药/肠-线粒体轴
```

**改动量 vs 你 ASTI 原稿：**
- 第1章全新（但可复用《脾胃论》经典论述）
- 第2章复用你原稿3.3.1/3.3.2的代谢重编程写法，但删去免疫信号，只留线粒体
- 第3章是新增，最值钱，需写两套时间刻度的错位（中医“脾虚日久” vs 现代“线粒体功能急性失代偿”）
- 第4章把你原稿4.1的“皂苷/黄酮/生物碱”分类废止，改为按治则

## 5 中药条目三段式写法（范文①最值得抄的）

**错误写法（你 ASTI 原稿的写法，只有现代机制）：**
> 黄芪甲苷IV可通过PGC-1α通路改善线粒体功能[60]。

**正确写法（三段式）：**

> **黄芪味甘性温，归脾肺经，功善补气升阳、健脾益肺，为补气要药，**“脾为后天之本，气血生化之源”，黄芪得土气之正，善补中气以生精微；现代药理研究表明，其主要活性成分黄芪甲苷IV可通过激活AMPK-PGC-1α-TFAM轴，促进线粒体生物发生，上调mtDNA复制与OXPHOS相关基因表达，显著提升骨骼肌细胞ATP含量并降低ROS与MDA水平[xx]；在慢性疲劳小鼠模型中，黄芪多糖可使力竭游泳时间延长32%，SOD活性提升19.2%[2]。

**每味药必须包含：**
1. 中医功效定位（引经典，归经，君臣佐使）
2. 现代药理机制（具体通路+分子+效应指标）
3. 证据与出处（模型+数据+文献）

> 疲劳性亚健康是介于健康与疾病之间的临界状态，以持续性疲劳、注意力不集中为核心表现，SHSQ-25量表评估显示我国城市人群发生率达60-70%。线粒体作为细胞能量枢纽，其生物发生障碍（PGC-1α/TFAM轴抑制）、能量代谢重编程（OXPHOS↓向糖酵解代偿）及过度自噬是疲劳发生的分子基础。中医学将疲劳性亚健康归入“虚劳”“脾虚”范畴，《黄帝内经》言“脾气散精，上归于肺”，《脾胃论》谓“脾胃内伤，百病由生”，脾虚失运则精微不布、清阳不升，发为疲劳。近年来研究揭示，线粒体功能障碍正是“脾虚生疲”的微观映射，痰湿内蕴则对应ROS蓄积与低度炎症放大。本文系统综述疲劳性亚健康“脾虚生疲”病机的理论内涵、线粒体能量代谢重编程的分子机制、二者对接的生物学纽带，并按健脾益气、化痰祛湿、疏肝健脾三法梳理中医药干预策略，提出“时窗-靶点-给药”对应框架与证据分级体系，为亚健康的中医药早期干预提供理论依据与转化路径。

关键词：疲劳性亚健康；脾虚生疲；线粒体；能量代谢重编程；治未病；中医药干预
