## 先看结论

作者列按 Vancouver 候选格式记录：通常列出前六位作者后用 `et al.`；作者少于或等于六位时列全。每条记录同时保留 PubMed 和 DOI 稳定链接，便于最终 citation freeze。

- 16 篇 = 最初 11 个 PDF + 后续 4 个 SHS context/multi-omics PDF + 1 个 telomere PDF。
- 只有 3 篇是 direct SHS–cortisol candidate reports：Yan 2012、Yan 2015、Yan 2018。
- 这 3 篇也没有进入 locked primary pooled meta；它们只支持 study-level narrative synthesis。此前的三研究 pooled calculation 仅为 exploratory audit material。
- `ijerph16173007.pdf` 已核验为与当前 SHS/cortisol 项目无关的文章，明确排除。
- 四个 context PDF 与 telomere PDF 可支持 bridge/context 叙述，但不能改写为 direct SHS–cortisol evidence。
- 这 16 篇来源文件中不包含最初的“多轴慢性压力”概念综述；该文章属于另一个 conceptual/framework reference，应单独核验和列示。

## 审计底表规则

1. 文章身份以 exact title + PMID/PubMed + DOI/DOI URL 为准。
2. PDF hash 只证明收到并审计的是具体文件，不证明研究具有可合并性。
3. “来源文件已审计”不等于“文章进入 meta-analysis”。
4. “SHS context”不等于 direct SHS biomarker evidence。
5. bridge/transfer evidence 不得替代 direct SHS evidence。
6. 16 篇来源文件中的 3 篇 cortisol report 不能被描述为正式最终 Meta 纳入文献；它们只能作为 study-level narrative evidence。此前三研究计算必须标注 exploratory，或从对外投稿稿中删除。
