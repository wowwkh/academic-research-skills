## 1 BBI/NBR 综述政策拆解（基于官网 Guide for Authors + 2026-06-14 NBR submission guide）

### BBI Guide for Authors（https://www.sciencedirect.com/journal/brain-behavior-and-immunity/publish/guide-for-authors）

> **Reviews**: The journal publishes invited or unsolicited reviews on a contemporary topic, discussed authoritatively with the aim of providing a solid, and often novel, interpretation of research evidence, and of integrating a mechanistic model when applicable. Reviews consist of approximately 6,000 words of text and no more than 100 scientific references. Reviews must contain at least one figure highlighting the key aspects of the article, complete with explanatory figure legends

**解读**：BBI 接受 unsolicited reviews，但要求 (1) contemporary topic, (2) authoritative discussion, (3) solid and often novel interpretation, (4) integrating a mechanistic model when applicable, (5) ~6000 words, ≤100 refs, ≥1 figure。我们的稿件已满足 (1)(3)(4)(5)，但字数10458w超6000w需压缩至6000w或转投 BBI Health（无字数严格限制），且需在 cover letter 强调 mechanistic model (SLIM) + novel interpretation (reversible continuum quantification + time-window-target matrix)。

**Desk rejection 潜台词**："typically does not publish reviews unless systematic, invited, meta-analytic or of exceptional quality" 意味着编辑初筛时认为稿件 (a) 非 systematic (无 PROSPERO, 无 RoB, 无 GRADE), (b) 非 invited, (c) 非 meta-analytic, (d) 未达到 exceptional quality threshold (无 quantitative thresholds, 无 verifiable predictions, 无 translational roadmap)。因此需在 (a)(c)(d) 上升级。

### NBR Guide for Authors（https://www.sciencedirect.com/journal/neuroscience-and-biobehavioral-reviews/publish/guide-for-authors）

> Review Articles: original and significant review articles, no word count stipulation, in depth, scholarly and comprehensive, original and not a mere summary of previous reviews without addition of novel knowledge, perspective, or theory. Data cannot be original on their own and should be already published. We do not publish empirical papers, and no unpublished data should be included. New analyses and modelling of previously published and publicly available dataset are allowed as long as essential to support narrative. Simple data re-analyses (including meta-analyses) without a new conceptual or theoretical framework will not be considered. We welcome review articles from clinical researchers whose submission exceeds high-quality threshold and significantly advances understanding.

**Manusights 2026-06-14 NBR submission guide**：NBR selective ~20-25% acceptance, 40-50% desk rejection, editorial standard requires rigorous integrative synthesis, systematic methods, clear brain-and-behavior contribution. Narrative reviews routinely desk-rejected when abstract promises synthesis but methods section gives no reproducible search strategy, screening criteria, coding framework, evidence-integration logic. PRISMA expectation: editors expect PRISMA reporting for systematic reviews. Missing PRISMA flow, RoB, data/code availability triggers early rejection.

**解读**：NBR 接受 unsolicited reviews，但要求 (1) original and significant, (2) in depth scholarly comprehensive, (3) novel knowledge/perspective/theory (not mere summary), (4) systematic methods + PRISMA reporting, (5) brain-and-behavior contribution direct. 我们的稿件满足 (1)(2)(3)(5)，但 (4) systematic methods 需加强：需在 Methods 明确 search dates, inclusion criteria, screening logic, coding methods, PRISMA flow, RoB, data/code availability。

### 路径A：升级为 Full Systematic Review with Meta-Analysis（满足 systematic + meta-analytic，冲 BBI 原刊）

**目标**：将 Critical Review 升级为 Systematic Review with Meta-Analysis，符合 BBI "systematic, meta-analytic" 要求，消除 desk rejection 借口

4. **Mini Meta-Analysis**：对 α direct biomarkers 可定量合并：

   - **Cortisol**：PMC6107457 205.80±29.82 vs 161.80±7.79 ng/ml，另有2篇 SHS+cortisol 直接，提取 mean±SD，随机效应模型 SMD

# Mini meta-analysis for cortisol, NLR, HRV, prevalence
# pip install numpy scipy matplotlib
import numpy as np

# Example: cortisol 205.8±29.82 vs 161.8±7.79, n1=... n2=...
# SMD = (mean1-mean2)/pooled SD
def smd(mean1, sd1, n1, mean2, sd2, n2):
    pooled_sd = np.sqrt(((n1-1)*sd1**2 + (n2-1)*sd2**2)/(n1+n2-2))
    return (mean1-mean2)/pooled_sd

# Random-effects DerSimonian-Laird
def random_effects(effects, variances):
    # effects = SMDs, variances = SE^2
    # Fixed effect weights
    w_fixed = 1/np.array(variances)
    fe = np.sum(w_fixed*np.array(effects))/np.sum(w_fixed)
    Q = np.sum(w_fixed*(np.array(effects)-fe)**2)
    df = len(effects)-1
    # Tau^2
    tau2 = max(0, (Q-df)/(np.sum(w_fixed) - np.sum(w_fixed**2)/np.sum(w_fixed)))
    w_random = 1/(np.array(variances)+tau2)
    re = np.sum(w_random*np.array(effects))/np.sum(w_random)
    se_re = np.sqrt(1/np.sum(w_random))
    I2 = max(0, (Q-df)/Q*100) if Q>0 else 0
    return re, se_re, tau2, Q, I2

# Example usage for cortisol 3 studies
effects = [1.2, 1.0, 1.3] # SMDs from 3 SHS+cortisol studies
variances = [0.05, 0.06, 0.04] # SE^2
re, se, tau2, Q, I2 = random_effects(effects, variances)
print(f"Random-effects SMD {re:.2f} SE {se:.2f} tau2 {tau2:.3f} Q {Q:.2f} I2 {I2:.1f}%")
