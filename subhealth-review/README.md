## 🎯 当前主方案（你确认的）

**选题A：线粒体动力学失衡作为亚健康多系统症状的统一细胞器基础：从分裂/融合失调到可逆性干预窗口**

- **英文**：Mitochondrial dynamics imbalance as a unifying organelle basis for multi-system symptoms in subhealth
- **核心模型**：SMDM模型（Subhealth-Mitochondrial Dynamics Model）
- **分子深度**：Drp1 Ser616↑/Ser637↓、Mfn2/OPA1↓、PINK1/Parkin自噬障碍、mtDNA泄漏→cGAS-STING→IL-6↑1.3-1.8倍
- **多系统映射**：疲劳（肌肉）、心悸（心HRV↓）、胃肠不适（肠屏障↓）、易感冒（单核促炎）、注意力↓（小胶质）
- **可逆窗口**：健康融合主导→亚健康早期轻度分裂可逆→迁延期过度分裂部分可逆→疾病不可逆碎片化
- **纯现代干预**：运动（AMPK-AKAP1-Ser637）、睡眠/时间疗法（生物钟-Drp1节律）、丁酸（Mfn2）、MitoQ/SS-31、间歇禁食，**完全去掉中医**
- **目标期刊**：Neurosci Biobehav Rev (8.2), Brain Behav Immun (8.5), Trends Endocrinol Metab (11)
