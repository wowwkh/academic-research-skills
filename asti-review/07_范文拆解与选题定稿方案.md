### 1.2 由标题推出的模板规律（可直接复用的判据）

1. **一条机制轴 > 五条机制轴。** 三篇范文的机制轴都只有一个（糖酵解／自噬／极化）。机制轴越多，每条的论证深度越薄，越像教科书章节而非综述。
2. **疾病宽度与辨识度成反比。** 范文③的"肺系疾病"看似覆盖面大，实则因为无钩子、无主张，读者无法从中获得任何别处得不到的结论——这正是你担心的"宽但空"。
3. **中医理论钩子是窄选题的"放大镜"。** 范文①把一个极窄的机制（糖酵解）与一个中医理论（脾不散精）绑定，立刻获得理论合法性 + 中医期刊的天然落点。**窄选题 + 理论钩子 = 高辨识度；窄选题 + 无钩子 = 看起来就是"没人做过的边角料"。**
4. **落点措辞决定文章野心。** "研究进展" = 被动综述；"机制与策略" / "干预策略" = 主动提出框架。审稿人与编辑对后者的评价显著更高。

## 3 定稿方案：伤科三期辨证 × 巨噬细胞时相极化

### 3.1 立论逻辑

```
中医伤科：三期辨证（时间刻度明确、临床可操作、有经典依据）
              ↕  映射 / 错位 / 校准
免疫学：  巨噬细胞时相极化（0–72h M1 → 3–7d 转换 → >7d M2 → 重塑）
              ↕
中药：    活性成分与复方的时相差异化干预（时窗—靶点对应）
```

**核心论点（本文的主张）：**

> 现行中医药干预 ASTI 的机制研究，普遍以"促 M2／抑 M1"为唯一评价终点，忽略了**干预时相**这一决定性变量。同一成分在不同时相可能产生相反效应（例：隐丹参酮在肿瘤语境下 M2→M1[69]；生脉散类在创面修复中促 M2）。中医伤科"初期消、中期和、后期补"三法本已隐含时相思想，但其时间刻度（1–2周／3–6周／7周以上）源自骨折愈合观察，**与软组织损伤的免疫时相（0–72h／3–7d／2w–数月）存在系统性错位**。本文提出按免疫时相校准的"时窗—治法—靶点"对应框架，并逐格标注现有证据的强度与空缺。

### 3.2 这个立论为何只有 ASTI 能做

| 备选疾病 | 能否支撑"时相 × 治法"框架 | 原因 |
|---------|----------------------|------|
| **ASTI** | ✅ **能** | 三阶段病理清晰、时程短（0–72h 到数月）、中医伤科三期辨证本身就是按时间分期的、且存在明确的疗效评价终点（肿痛、功能、影像） |
| 动脉粥样硬化 | ❌ 不能 | 慢性进展性疾病，无清晰三阶段 |
| 急性肺损伤 | ⚠️ 部分 | 有急性期与消退期，但中医"三期"不适用（肺系无伤科三期） |
| 肺系疾病（系统级） | ❌ 不能 | 病种异质性过大，无法共用一套时相 |

**→ "窄"在这里是必要条件，不是缺点。** 这一条可以直接回应你的原始疑问。
